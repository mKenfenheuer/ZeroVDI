# Help &amp; Guides

Welcome to **ZeroVDI** — your remote desktops, right in the browser. No software to install: if
you can open this page, you can connect to a desktop.

This guide walks you through everything you need as a day-to-day user.

## Where to start

| If you want to… | Read |
|---|---|
| Connect to a desktop for the first time | [Getting started](getting-started.md) |
| Learn the in-session controls (full screen, clipboard, files) | [Using the console](using-the-console.md) |
| Turn audio, clipboard, camera or microphone on or off | [Connection settings](connection-settings.md) |
| Save your sign-in so you don't retype it every time | [Saving your credentials](saving-credentials.md) |
| Set up two-factor authentication or change your password | [Your account](your-account.md) |
| Fix a connection that won't start or looks wrong | [Troubleshooting](troubleshooting.md) |

> Looking for setup, configuration, or administration topics? Those live in the separate
> **administrator guide**, available to administrators from the admin area.
