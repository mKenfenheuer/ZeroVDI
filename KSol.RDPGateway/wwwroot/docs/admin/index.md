# ZeroVDI Documentation

Welcome to the administrator documentation for **ZeroVDI** — a self-hosted RDP gateway and
virtual-desktop (VDI) broker built on top of Proxmox VE.

ZeroVDI lets you publish Windows and Linux desktops to your users through a pure browser-based
console (no client install), broker automatically-provisioned desktop pools, enforce device and
security policy centrally, and keep a complete, tamper-evident audit trail of who connected to what.
