# Getting started

ZeroVDI runs entirely in your web browser. There is nothing to download or install — you sign in,
pick a desktop, and connect.

## Signing in

Open the ZeroVDI address your administrator gave you and sign in with your username and password. If
two-factor authentication is required for your account, you'll also be asked for a one-time code —
see [Your account](your-account.md) to set that up.

If your organisation uses **single sign-on**, there is a **Sign in with …** button below the password
box instead — use that and you'll sign in with your usual work account. Your account is created
automatically the first time.

## Your desktops

After signing in you land on the **Your desktops** dashboard. Each card is a remote desktop you've
been given access to:

- A **single desktop** shows a power badge (running, stopped, …).
- A **pool** is marked with a *Pool* badge. The first time you connect, a personal desktop is created
  for you automatically — it may take a minute the first time.

If you don't see any desktops, you haven't been assigned one yet. Contact your administrator.

## Connecting

1. Click **Connect** on a desktop card. The console opens in a new browser tab.
2. If the desktop is stopped or suspended, ZeroVDI powers it on for you — give it a moment to boot.
3. If your sign-in hasn't been saved, you'll be prompted for the desktop's username and password.
   (You can [save these](saving-credentials.md) so you're not asked again.)

Once connected, the remote desktop appears in the tab and you can work in it as if it were in front
of you. See [Using the console](using-the-console.md) for the in-session controls.

## Disconnecting vs. signing out

- **Closing the console tab** disconnects you but usually leaves your session running on the desktop,
  so your apps are still open when you reconnect.
- **Signing out inside the remote desktop** (its Start menu / log-off) ends the Windows/Linux session.

When you're done with ZeroVDI itself, use the account menu in the top-right corner to **log out**.
